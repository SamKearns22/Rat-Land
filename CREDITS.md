### Attribution gap — please read

Only `buildings.png` could be positively identified: a web search
surfaced a specific OpenGameArt page whose stated submission date
(2020-09-20) exactly matched the file's own embedded XMP metadata
(`ModifyDate: 2020-09-20T16:11:15+03:00`) — an independent match, not
just a guess, so that attribution is trustworthy.

For `cave.png`, `ruins_tileset.png`, and `sewer_1.png`, no embedded
metadata (artist, title, source) was present in the files themselves,
and searches for candidate OpenGameArt pages returned multiple
plausible matches with no way to confirm which (if any) was correct —
one search result even attributed a "sewer tileset" page to an
obviously wrong name, which is exactly the kind of bad guess this file
must not repeat. CC-BY licensing requires real, correct attribution;
placeholder or guessed attribution is worse than none, since it looks
compliant without being compliant.

**If you have the original download page, itch.io listing, or zip
file these three came from, please provide the artist name and URL so
this file can be corrected before any of these three ship in a public
build.**
